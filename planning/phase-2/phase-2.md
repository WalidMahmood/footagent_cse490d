# Phase 2 - 3D Digital Twin UI

## Goal
Stream frame-level world state to an interactive 3D football digital twin.

## Exit Criteria
- [ ] Stream processor emits frame updates
- [ ] FastAPI WebSocket endpoint stable
- [ ] Three.js pitch and entities rendered correctly
- [ ] Camera controls and overlays usable
- [ ] End-to-end demo clip captured
